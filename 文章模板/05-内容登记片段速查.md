# 05 内容登记片段速查（复制粘贴用，不需要保存到别处）

这里是新建/修改「专栏 Topic」与「Wiki 知识库」时需要粘贴到 `source/_data/` 的登记片段。
所有片段都是 YAML，`#` 注释与 `【】` 占位在粘贴后替换、删除。登记完运行 `npm run doctor` 检查。

---

## 一、把文章挂进已有专栏（只改文章 Front Matter）

在 `source/_posts/` 的文章 Front Matter 里加：

```yaml
collection:
  profile: topic
  id: 【专栏id】   # 本站已有：system-thinking
```

文章会同时出现在博客列表与这个专栏里，其余字段照普通文章填写。

---

## 二、新建一个专栏

1. 在 `source/_posts/` 写好第一篇专栏文章，Front Matter 里带上上面的 `collection`。
2. 新建 `source/_data/topic/【新专栏id，英文短横线】.yml`，内容：

```yaml
# source/_data/topic/【专栏id】.yml
name: 【专栏名称，例如：系统化整理】
headline: 【一句话主标题】
description: 【专栏介绍，会显示在专栏卡片上】
route:
  start: 【第一篇文件名（不含 .md）】   # 作为专栏起点页
article:
  style: tech   # 可选：文章阅读风格（tech / story 等），不写用默认
```

3. `npm run doctor` 确认归属，再 `npm run server` 从 `/topic/` 入口检查。

---

## 三、给已有 Wiki 项目加一篇文档（最常用）

1. 新建正文 `source/wiki/【项目id】/【文件名】.md`（模板见 `04`）。
2. 打开 `source/_data/wiki/【项目id】.yml`，在 `navigation.tree` 里登记：

```yaml
# 在 navigation.tree 的分组下加一行：只写文件名，不带 .md 和路径
navigation:
  tree:
    【已有分组名】:
      - 【已有文件名】   # 原有行保留
      - 【新文件名】     # ← 新增这一行
```

想单独开一个分组，就在 tree 里加一个键：

```yaml
navigation:
  tree:
    【已有分组】:
      - index
    【新分组名】:
      - 【新文件名】
```

---

## 四、新建一个 Wiki 项目

1. `source/_data/wiki.yml`（上架列表）加一行项目 id：

```yaml
# source/_data/wiki.yml
- 【项目id】          # 例如：knowledge-management
- 【另一个项目id】    # 新项目在这份清单里追加一行
```

2. 新建 `source/_data/wiki/【项目id】.yml`：

```yaml
# source/_data/wiki/【项目id】.yml
name: 【项目短名，例如：个人知识管理】
headline: 【主标题，例如：让笔记重新派上用场】
tagline: 【副标题】
description: 【项目介绍，会显示在 Wiki 列表卡片上】
tags:
  - 【项目标签】      # 用于 Wiki 之间的相关推荐
audience: 【目标读者，例如：学习者与写作者】
route:
  path: /wiki/【项目id】/
navigation:
  tree:
    【分组一】:
      - index        # 首页文件
      - 【文件名二】
    【分组二】:
      - 【文件名三】
```

3. 在 `source/wiki/【项目id】/` 下按 04 模板创建首页 `index.md` 和各篇文档，
   每篇 Front Matter 都要有 `permalink: wiki/【项目id】/【文件名】/`。
4. `npm run doctor` 验证归属与目录树，再从 `/wiki/` 入口预览整个项目。

---

## 五、需要提醒的事

- 文件名 = 目录树键 = 网址末段，三处必须一致，否则文档进不了左侧导航。
- `navigation.tree` 里的顺序就是侧栏与"上一篇/下一篇"的顺序。
- 分组名按"任务/阅读阶段"命名，比按标题堆砌更好用（参考 site-handbook 的现有分组）。
- 新建或改名后，旧链接会失效，发布前确认一遍 URL。
