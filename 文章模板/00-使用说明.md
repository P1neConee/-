# 文章模板 · 使用说明

这个文件夹是你的**模板库**：每种文章结构一份可直接复制填写的模板。它放在博客根目录，Hexo 只渲染 `source/` 里的内容，所以这里的文件**不会被发布**，可以放心写注释、占位符。

> **配套体系**：模板负责"怎么写"，根目录《[使用与配置手册](../使用与配置手册.md)》负责"为什么这样配 + 还能怎么改"（站点配置、Front Matter 参考、集合登记、Widget、命令流程等）。两份文件配合使用。

## 模板与保存位置对照

| --- | --- | --- | --- |

## 标准使用流程

1. 把对应模板复制到上表的保存位置，**文件名直接改成英文短横线命名**（例如 `weekly-review-2026-09-05.md`）。
2. 文件名就是网址：博客文章是 `/posts/文件名/`，Wiki 文档是 `/wiki/项目ID/文件名/`。**发布后不要改名**，否则旧链接失效。
3. 打开文件，把 Front Matter 里带 `【】` 的占位内容替换成真实信息，删掉注释行。
4. 如果模板里要求登记（Topic / Wiki），按模板底部的「需要同步登记」步骤操作。
5. 检查一遍：`npm run doctor`，然后 `npm run server` 打开预览确认。

## 最容易踩的三个坑

- **不要照搬网上旧教程的 Front Matter 字段**。旧版 Stellar 常用的 `wiki:`、`widgets:`、`banner:` 等顶层字段在本主题会被当作未知字段报错。本博客主题的写法以这里四类模板为准。
- **文件名决定网址**，Front Matter 里的 `title` 只影响显示标题。想改网址就改文件名。
- **Wiki / Topic 内容改完位置或归属后**，记得同步 `source/_data/` 里的登记文件，`npm run doctor` 会帮忙检查归属是否一致。

## 常用分类与标签

博客文章的 `categories`（分类）建议沿用现有的稳定领域：`方法`、`工具`、`学习`、`思考`、`观察`、`记录`。`tags`（标签）可以灵活添加，用来跨文章连接同一主题（如 `知识管理`、`系统思维`、`回访`）。

> 本博客未启用「笔记本 Notebook」形态；如果以后启用，结构与 Wiki 类似（正文目录 + 注册 YAML），可参考 `05` 的登记写法。
