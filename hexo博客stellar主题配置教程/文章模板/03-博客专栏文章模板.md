### 需要同步登记？

- **挂进已有专栏**：只改 `collection.id` 为已有专栏 id 即可，其余字段照填。
- **新建一个专栏**：除本文外，还要在 `source/_data/topic/新建id.yml` 登记专栏本身
  （name / headline / description / route.start / article.style），模板见 `05-内容登记片段速查.md`。
- 用 `npm run doctor` 检查归属后，再 `npm run server` 预览。
